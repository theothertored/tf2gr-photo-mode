TF2: Gold Rush Photo Mode

Camera controls for taking screenshots on a local server.
exec photomode to start taking photos,
exec photomode_off to return to normal.

Choose:

  • with SourceRes if you want to take screenshots in higher or unusual resolutions (e.g. 4K on a 1080p screen, phone wallpapers)
    NOTE: This page provides a 64 bit build of SourceRes for your convenience, which is not the same as the original SourceRes plugin.
  • without SourceRes otherwise.

Setup

  • Extract the ZIP into steamapps\common\Team Fortress 2 Gold Rush\. Here's where the files should land:
    • *.cfg → tf_goldrush\cfg\,
    • photomode.nut → tf_goldrush\scripts\vscripts\,
    • SourceRes.dll, SourceRes.vdf → tf_goldrush\addons\
    • tga-to-png.bat → tf_goldrush\screenshots\.
  • Check the binds in photomode_off.cfg match yours (see Keybinds).
  • For SourceRes only: add -insecure -windowed to Gold Rush's launch options. The console should print SourceRes 2.1 loaded. if it works.

Usage

Start a local server (for example map pl_goldrush), then open the console and run exec photomode. It needs your own server: it turns on sv_cheats and runs a server-side script.

Entering photo mode puts the round into the tournament “ready up” state, so no round timer runs, and pauses any timers on the map. It turns on noclip and hides the HUD and your weapon.

Keys Action
Ctrl + scroll FOV, 10–120 in steps of 5
Shift + scroll Fly speed: 0.1, 0.25, 0.5, 1, 2.5, 5, 10, 15, 20
Alt + scroll Tilt the camera, ±45° in steps of 5°
Ctrl / Shift / Alt + middle click Reset the respective value to default
L Reset FOV (90), fly speed (5) and tilt (0)
R / F Fly up / down
H Toggle the HUD

exec photomode_off turns noclip and cheats off, resets the camera and restarts the round. Leave photo mode in open space: if you exit inside a wall, you stay stuck.

After a map change, run exec photomode again.

Keybinds

Photo mode rebinds Ctrl Shift Alt R F H L, the scroll wheel and middle click. photomode_off.cfg sets them back to Gold Rush's defaults, not to whatever you had.

If you've changed any of them, type bind and the key in the console before entering photo mode:

bind ctrl
"ctrl" = "+duck"

Use the command you get (+duck in this example) for the bind in photomode_off.cfg.

The game saves your binds when you quit. Run exec photomode_off before quitting, or photo mode's binds will still be there next time.

Graphics settings

photomode.cfg raises a few detail settings:

  • mat_picmip -10: highest texture resolution. Uses more video memory.
  • r_rootlod 0: full-detail models. May need a map reload to apply.
  • cl_detaildist 20000: grass and other detail props stay visible far away.

photomode_off.cfg only sets cl_detaildist back to 1200. If you normally use other values for the first two, add them to its commented-out lines.

Static props fade at distances set by each map, no console command can change that.

Higher-resolution screenshots

SourceRes lets the game render at sizes your monitor doesn't support, in windowed mode only:

sr_force 3840 2160
screenshot

For smoother edges, render at twice the size you need and scale the image down. To get back to normal, set your resolution again in the video options, or through a command: mat_setvideomode 1920 1080 0 (fullscreen 1080p).

Getting the full-quality files

The copies in your Steam screenshot library are compressed. The game also saves each screenshot uncompressed, as a TGA file, in:

steamapps\common\Team Fortress 2 Gold Rush\tf_goldrush\screenshots

tga-to-png.bat in that folder converts every TGA there to PNG and then deletes the TGA files. You must have ImageMagick 7 installed.
